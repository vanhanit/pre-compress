# Contributing

Contributions are welcome. Open an issue to discuss larger changes before starting on them.

## How to contribute

1. Fork the repository and create a branch from `master`.
2. Follow the commit, testing and dependency rules in [AGENTS.md](AGENTS.md). They apply to people as well as AI agents.
3. Run `npm run check` before pushing.
4. Open a pull request to `master` and confirm that you agree to the Contributor License Agreement below.
